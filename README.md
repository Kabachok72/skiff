# Skiff для чайников

Русский учебник и тренажёр (с ритм-игрой) по прошивке [Skiff](https://github.com/illuminus5/skiff) для M-VAVE FM-1.

- Тренажёр: https://kabachok72.github.io/skiff/
- Справочник: https://kabachok72.github.io/skiff/uchebnik.html

Подключение FM-1 по MIDI работает в Chrome или Edge (компьютер, Android).
